Metadata untuk YouTube Studio

🎬 Buka YouTube Studio ↗

Simpan record ke database

Setelah selesai upload di Studio, tempel 11-karakter video ID atau URL penuh YouTube di bawah. Sistem akan mencatat reviewer, waktu, dan menulis .metadata.json pendamping di samping MP4.

Contoh format yang diterima: ID 11 karakter, short URL youtu.be, atau URL panjang www.youtube.com/watch?v=

📌 Panduan Studio 6 langkah

  1. Klik Buka YouTube Studio ↗ di panel kiri, lalu pilih menu Create → Upload videos (ikon kamera +).
  2. Drag-drop file MP4 dari path: /app/static/clips/{{ clip.podcast }}/{{ clip.episode }}/{{ clip.manual.video_filename }}
  3. Panel kiri → Copy judul, Copy deskripsi, Copy tags. Tempel masing-masing ke tab Details di Studio. Pastikan #Shorts ada di akhir judul.
  4. Thumbnail bisa pakai auto atau upload gambar pilihan. Visibility → set ke Public, klik Publish. Tunggu sampai videonya punya URL ID (11 karakter).
  5. Balik ke halaman admin ini, copy-paste ID video atau URL penuh ke form "Simpan record ke database" di atas → klik Simpan manual upload.
  6. Sistem otomatis menulis file {{ clip.manual.video_filename }}.metadata.json pendamping di samping MP4 sebagai arsip record.

Catatan upload API vs Manual

Quota harian ~10–20 upload/hari per channel. Kalau limitnya kena, gunakan Manual Studio; quota reset besok pagi.
Duplicate check Sebelum meng-upload via API, admin panel cek database — jika sudah tercatat uploaded atau manual, tombol ganti jadi "Selesai".
Re-upload Hapus record di app/data/admin.sqlite3 tabel youtube_uploads kalau ingin bikin record ulang.
