Buka YouTube Studio ↗

Setelah Anda unggah MP4 di Studio dan video sudah punya ID, tempel 11-karakter ID atau URL penuh YouTube di bawah lalu klik Simpan. Catatan status akan diperbarui otomatis.

Langkah-langkah Studio:

  1. Klik Buka YouTube Studio, lalu Create → Upload videos.
  2. Drag-drop file MP4 dari path di atas (folder /app/static/clips/{{ clip.podcast }}/{{ clip.episode }}/).
  3. Copy judul, deskripsi, tags, tempel masing-masing di tab Details Studio.
  4. Visibility: Public, Save → salin video ID.
  5. Balik ke halaman admin ini, tempel ID atau URL di form kiri → Simpan manual upload.
  6. Sistem akan menulis {{ clip.manual.video_filename }}.metadata.json di samping file MP4 sebagai bukti record.
